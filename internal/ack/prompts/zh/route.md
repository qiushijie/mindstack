# 查询路由

将用户问题映射到知识库现有标签集合，同时提取全文检索关键词。只返回一个 JSON 对象。

---

你正在帮助把用户问题路由到知识库中相关的文档。

用户问题: %s

知识库中可用的标签（每个标签后括号内为使用该标签的文档数量）:
%s

只返回一个形如 {"tags":[],"keywords":[]} 的 JSON 对象（不要 markdown 围栏）。

"tags": 与回答该问题最相关的标签。
- 标签必须来自上面列表（不得自己创造）
- 高频标签更稳定，但与问题表述直接匹配的低频标签也应保留
- 选择 2-5 个标签即可，不要过多
- 如果没有合适的，返回 []

"keywords": 3-8 个用于全文搜索的关键词。知识库文档混合了中文和英文内容。
- 优先提取完整的复合术语和领域专有名词（例如"权限控制"应提取为"权限控制"，"指数退避"应提取为"指数退避"）
- 如果问题中包含英文技术术语，直接保留原文（例如 "RBAC", "Kubernetes HPA"）
- 提取对应另一种语言的等价形式（例如 "retry policy" 对应 "重试策略"）
- 去除无区分度的虚词和通用词（如 "的""了""如何""什么""可以""system""approach""method"）
- 不要将复合词拆成单字

示例: {"tags":["api","rest"],"keywords":["权限控制","access control","rbac","指数退避"]}
