# Snippet Extraction

从文档中提取与用户问题最相关的片段。

---

你正在从一篇文档中提取与用户问题最相关的片段。注意：文档内容可能已被预筛选，只包含可能相关的区域；每行开头的行号是原文 markdown 的原始行号，可能不连续。

重要：返回的 location 必须使用每行开头显示的原始 markdown 行号，不得使用重新编号后的相对位置。

用户问题: %s

文档内容（原始行号:内容）:
%s

请提取最多 %d 个与用户问题最相关的连续片段。要求:
- 片段必须是原文中连续的行（原始行号连续）
- 每个片段长度不超过 15 行
- 优先选择直接回答问题的内容，其次是提供背景或相关细节的内容
- 如果行号不连续，可以在不连续处分割成多个片段
- 对每个片段给出 0-1 之间的相关度分数

只返回 JSON 数组（不要 markdown 围栏）:
[
  {"location": "#10-20", "score": 0.95}
]

如果没有相关内容，返回 []。
